# Yash Bangera — Portfolio

A single-page static portfolio site. No build step, no dependencies —
just `index.html`, `style.css`, and `script.js`.

## Before you deploy

Search the project for `PLACEHOLDER` comments and replace them:

- `index.html`
  - Hero links: email, GitHub, LinkedIn, resume file
  - **About**: your own 2–3 sentence narrative
  - **Experience**: your actual AWS title + 2–3 achievement bullets
  - **Projects**: swap the 4 placeholder cards for real projects (name,
    description, tags, links). Delete any you don't need.
  - Contact section email
- Add your own `resume.pdf` to this folder if you want the Resume button to work.

## Deploy

Either platform works with this project as-is — it's a static site, so there's
no build command to configure (leave build command empty, publish directory `/`).
